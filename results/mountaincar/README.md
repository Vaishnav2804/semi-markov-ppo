# MountainCar-v0 benchmark results

These are experimental results, separate from the correctness tests in `tests/`.

## Provenance

The runs were produced on 2026-11-23 by the research versions of the files now in `examples/mountaincar/`, on CPU,
one core per run.
* **Algorithm.** Every run's `config.json` records the sha256 of the algorithm file:
  `f3f24511a9701cb6836850f2873c4ac0ac18cd70c95c03470cdcc9803512bfd9`. `src/smppo/ppo.py` contains that exact code,
  plus a licence header.
* **Environment.** The public example environment was checked against the research environment: identical on 14,609
  steps across 90 episodes and all three arms.
* **What is included.** Configurations, final evaluations, learning-curve evaluations and runtime records.
* **What is omitted.** Checkpoints, model files, logs and per-episode training CSVs.

## Design

* Arms:
  * A1: stock MaskablePPO on MountainCar's 3 primitive actions;
  * A2: SemiMarkovMaskablePPO with duration 1;
  * A3: SemiMarkovMaskablePPO with durations {1, 2, 4}, giving 9 macro-actions.
* Seeds 0, 1 and 2 for every arm.
* 1,000,000 primitive steps per run, counted by `PrimitiveBudget`.
* PPO settings follow the RL Zoo MountainCar configuration (16 envs, n_steps 16, gae_lambda 0.98, γ 0.99, 4 epochs,
  ent_coef 0, SB3 defaults otherwise). Reward normalization is off and observation normalization is on.
* Evaluation:
  * final: 100 fixed starts (reset seeds 10000–10099), deterministic policy, normalization statistics frozen;
  * learning curves: every 50k primitive steps on the first 20 of those starts.
* Competence gate, fixed in advance: A1 must reach success ≥ 0.50. It reached 1.00 in every seed.

## Files

* `summary_per_seed.csv` and `summary_by_arm.csv` (mean and sd over seeds).
* `learning_curves.png`: thin lines are seeds, thick lines are the mean per 50k-step bin.
* `eval_distributions.png`: every evaluation episode shown as a point.
* Both figures and both summary CSVs are regenerated by `python examples/mountaincar/evaluate.py summary --runs results/mountaincar/runs --out <dir>`. The CSVs regenerate byte-identically.
* `runs/{arm}_s{seed}/`: `config.json`, `eval.csv`, `curve.csv`, `runtime.json`.
* `original_validation_test_report.json`: the research test suite's measured values from before these runs.

## Reproduce

```bash
for S in 0 1 2; do for ARM in A1 A2 A3; do
  python examples/mountaincar/train.py --arm $ARM --seed $S --prim_steps 1000000 --out runs/${ARM}_s${S}
done; done
python examples/mountaincar/evaluate.py summary --runs runs --out results/mountaincar_rerun
```

Measured wall time was about 5.5 min per A1 or A2 run and about 4.3 min per A3 run on one CPU core.
